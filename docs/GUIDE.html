FTE Studio

Figma → exact HTML/CSS → native Elementor (ACF PRO + Elementor PRO) → WordPress. Badhu free, tamara PC par. DeveloperAI skill na rules follow kare che.

Kem kaam kare che

.fig file / Figma plugin zip→ JSON + assets (free, offline)→ Exact HTML/CSS→ Native Elementor + Global styles→ WordPress (helper plugin)→ Accuracy check

Claude ne MCP thi jodi shakay: ek j tool fte_make badhu kare ane 6–8 line nu result aape (ocha tokens). Claude pachhi fakt polish/enhancement kare.

1. Setup (ek j vaar, ~5 min)

python.org → Download Python 3.14 → installer ma "Add python.exe to PATH" tick karo. (.fig file vanchva 3.14 joiye.)

Aa Pillow + Playwright install kare ane check chalave. Koi PowerShell command type karvani nathi.

Dekhase: OK Python, OK Pillow, OK Browser..., READY

Studio app → 2. WordPress tab → Make helper plugin zip. WP Admin → Plugins → Add New → Upload → FTE Studio Bridge Activate. Elementor, Elementor Pro ane ACF PRO active hova joiye.

WP Admin → Users → Profile → Application Passwords → name "FTE Studio" → Add. Aa password Studio app ma j nakho; app te save nathi kartu. Pela staging site par vapro. Kaam puru thay pachhi revoke karo.

2. Roj no upyog (desktop app)

Figma file (.fig) ke Figma plugin ni zip, Output folder ane (optional) Fonts folder select karo → Import design. Frames ni list aavse; double-click = exact HTML preview.

Dekhase: "Connected. WordPress 7.x · Elementor 4.x · Pro 3.x · ACF 6.x". Pro detect thay to "Elementor Pro installed" auto tick thase.

Global Colors/Typography Kit ma, images WebP Media Library ma (ek j vaar), page native widgets thi. Pro hoy to Header/Footer Theme Builder ma ane repeated cards Loop Grid + ACF fields + posts.

Live page ne exact HTML sathe pixel-compare kare: tolerant % ane strict %, ane diff image (laal = farak).

Pachhi Claude ne kaho:

  • "fte_extract thi Buell Client.fig extract karo F:\exports\buell ma" → fakt HTML/CSS + JSON + assets
  • "fte_make_site thi F:\exports\buell ni aakhi site WordPress par banavo, pro=true" → badha desktop frames pages bane, Home front page, Main Menu
  • "fte_make thi Home frame banavo ane accuracy kaho" → ek page + accuracy

Dar tool 4–8 line nu result aape (ocha tokens). Polish mate: fte_compare, fte_frame_brief.
